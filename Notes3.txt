Memoization is a optimization technique, where the results expensive calculation or function are stored or cached preventing from recomputing on ever renders until
How Does Memoization Help?
Reduces unnecessary calculations
Prevents unwanted re-renders
Improves performance in large applications

React provides three ways to memoize values, functions, and components:
- React.memo()
- useMemo()
- useCallback()

- React.memo(): is an higher order component takes in the child components only re-renders the child components if the props are changed.
                - A higher-order component (HOC) that memoizes a React component	Prevents unnecessary re-renders when props haven’t changed	Re-rendering of components

- useMemo: A hook that memoizes the result of an expensive calculation	Avoids recomputation of expensive values unless dependencies change	Recalculation of values

- useCallback()	A hook that memoizes a function instance	Prevents function recreation unless dependencies change	Recreating functions
